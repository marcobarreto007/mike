# Gmail API Notes

Captured: 2026-04-08

Why this matters to Mike:
- Mike already has Gmail MCP tools for inbox reading, message reading, and sending email.
- These notes anchor the behavior to the official Gmail API model.

Key points:
- `users.getProfile` is the lightweight way to confirm which Gmail account is connected; the profile response includes the authenticated email address and mailbox counters.
- `users.messages.list` is the standard inbox/message listing method and supports filters such as `labelIds`, Gmail search syntax through `q`, and result limiting through `maxResults`.
- Sending mail with the Gmail API is built around creating a MIME message, encoding it in base64url, and sending it with `users.messages.send`.
- Gmail search/filter behavior lives in the list call, while the full body of a single message is retrieved separately.

Operational notes for Mike:
- Use inbox listing to shortlist messages, then read individual emails only when needed.
- Prefer targeted Gmail queries for urgency, sender, or subject filters.
- Keep send-email flows grounded in the real MCP tool result, not in drafted text.
